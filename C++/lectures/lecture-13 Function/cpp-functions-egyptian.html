ANATOMY

function syntax

main.cpp
int add(int a, int b) {
  return a + b;
}

int result = add(3, 5);

int = return type · add = name · a, b = parameters

INPUT

arguments بتوصل الـ data

arguments.cpp
void greet(string name) {
  cout << "Hello " << name;
}

greet("Mona");
parameter هو variable في definition:
string name

argument هي القيمة وقت الـ call:
"Mona"

نفس function ممكن تاخد input مختلف كل مرة.

EXAMPLE 01

absolute value function

عايزين الناتج دايمًا موجب: لو الرقم بالسالب، نقلب إشارته.

absolute.cpp
int absolute(int number) {
  if (number < 0) return -number;
  return number;
}

cout << absolute(-12); // 12

IMPORTANT

return vs cout

cout = display

بيطبع value على الشاشة. مفيد للعرض، بس مش بيبعتها لـ code تاني.

cout << 10;
≠

return = give back

بيرجع value للي نادى function عشان يخزّنها أو يعمل عليها حسابات.

return 10;

في C++ مفيش echo keyword؛ غالبًا المقصود print زي cout.

EXAMPLE 02

max بين رقمين

max.cpp
int maxOfTwo(int first, int second) {
  if (first > second) return first;
  return second;
}

cout << maxOfTwo(17, 9); // 17

الـ function بتقارن، وبعدها return بيطلع الرقم الأكبر.

VOID

no params, no return

لو مش محتاجة input ومش هترجع value، استخدم void.

welcome.cpp
void printWelcome() {
  cout << "Welcome to C++!";
}

printWelcome();

بتعمل side effect: تطبع message، بس مش بترجع value.

DEFAULT ARGUMENT

function بـ default value

default.cpp
void printMessage(string text = "Hello!") {
  cout << text;
}

printMessage(); // Hello!
printMessage("Good morning");

لو مابعتّش argument، C++ تستخدم default value. لو بعتّ قيمة، هي اللي تتستخدم.

REVISION

نراجع بسرعة

  1. الـ function block باسم بيعمل task محددة.
  2. الـ arguments هي data بتبعتها وقت الـ call.
  3. return بيرجع value؛ cout بيطبعها.
  4. استخدم void لما مفيش value راجعة.
  5. default value بتشتغل لو مابعتّش argument.
