الأساس

Data Type يعني إيه؟

كل variable في ++C لازم يكون ليه نوع (type) محدد بيقول للـ compiler نوع البيانات اللي هيتخزن جواه، وحجم المساحة اللي هياخدها في الذاكرة. من غير الـ type، الـ compiler مش هيعرف يتعامل مع القيمة صح.

types.cpp
int age = 20;
// int = النوع  |  age = اسم الـ variable  |  20 = القيمة
03 / 14
الأرقام الصحيحة

int و long long

int بيخزن أرقام صحيحة (من غير كسور) زي 5 أو -10، بس ليه حد أقصى. لو هتشتغل برقم كبير أوي هيتعدى الحد ده (زي عدد سكان دولة)، تستخدم long long.

numbers.cpp
int age = 25;
int score = -10;
long long population = 8000000000;
// رقم كبير أوي مفيش مكان له في int
04 / 14
الحروف والنصوص

char و string

char بيخزن حرف واحد بس بين quotes مفردة ' '. string بيخزن مجموعة حروف (نص) بين quotes مزدوجة " "، وعشان تستخدمه لازم تعمل #include <string>.

text.cpp
#include <string>

char grade = 'A';
string name = "Mohamed";

القيم المنطقية

bool

bool بيخزن قيمة من اتنين بس: true أو false. بتستخدمه في الشروط والقرارات جوه البرنامج.

bool.cpp
bool isStudent = true;
bool isPassed = false;

الكسور العشرية

float و double

لو القيمة فيها كسور عشرية زي 3.14 أو 19.99، تستخدم float أو double. double بيدي دقة أعلى ومساحة أكبر، وده اللي بنستخدمه في الغالب.

decimals.cpp
float price = 19.99f;
double pi = 3.14159265;
// double أدق وأشيع استخدام

قواعد التسمية

تسمية الـ variables

  • —الاسم لازم يبدأ بحرف أو underscore ( _ )، مش رقم.
  • —ممنوع مسافات أو رموز زي @ # - جوه الاسم.
  • —++C بيفرق بين الحروف الكبيرة والصغيرة، يعني age و Age اسمين مختلفين تمامًا.
  • —متستخدمش keywords زي int أو return كاسم لـ variable.
  • —الاسم الواضح أحسن من الحرف الوحيد: studentAge أوضح بكتير من a.
naming.cpp
✓ صح
int studentAge = 20;
int _score = 90;

✕ غلط
// int 2age = 20;      لا يبدأ برقم
// int student age;    فيه مسافة

Assign Value

بتدي قيمة للـ variable إزاي

تقدر تدي القيمة وانت بتعرّف الـ variable (declare + assign مع بعض)، أو تعرّفه الأول وتديله القيمة بعد كده.

assign.cpp
int age = 20;
// declare و assign في سطر واحد

int score;
score = 95;
// declare الأول، وassign بعد كده

Update Value

بتغيّر القيمة إزاي

تقدر تغيّر قيمة الـ variable في أي وقت بعد كده — بس النوع بتاعه ثابت ومش بيتغير.

update.cpp
int score = 95;
score = 100;
// اتحدثت القيمة القديمة بقيمة جديدة

score = score + 5;
// بناء على القيمة القديمة نفسها

Input

cin — تاخد قيمة من المستخدم

cin بتستخدمها عشان تاخد input من المستخدم من الـ keyboard، ولازم تعمل #include <iostream> عشان تستخدمها.

input.cpp
int age;
cout << "Enter your age: ";
cin >> age;
// المستخدم كتب رقم، اتخزن جوه age

خد بالك

cin للأرقام مقابل النصوص

cin >> مع رقم (int, double...) بتقرا لحد أول مسافة. لو عايز تقرا سطر كامل فيه مسافات (زي الاسم الرباعي)، تستخدم getline(cin, variable) بدل cin >>.

cin_vs_getline.cpp
✓ رقم
int age;
cin >> age;
// شغالة عادي مع الأرقام

✓ نص فيه مسافات
string fullName;
getline(cin, fullName);
// cin >> fullName هتوقف عند أول مسافة بس

مثال شامل

كل الأنواع مع بعض

دلوقتي خلينا نجمع كل الـ types والـ input في برنامج واحد كامل.

full_example.cpp
#include <iostream>
using namespace std;

int main() {
    string name;
    int age;
    double gpa;
    bool isPassed;

    cout << "Enter your name: ";
    getline(cin, name);

    cout << "Enter your age: ";
    cin >> age;

    cout << "Enter your GPA: ";
    cin >> gpa;

    isPassed = gpa >= 2.0;

    cout << name << " - Age: " << age << " - Passed: " << isPassed;
    return 0;
}

Revision

اللي لازم يفضل في دماغك

كل variable لازم يكون ليه type يحدد نوعه وحجمه في الذاكرة.
int للأرقام الصحيحة، long long للأرقام الكبيرة أوي.
char لحرف واحد، string لنص كامل.
float/double للكسور، bool للـ true/false.
اسم الـ variable يبدأ بحرف، من غير مسافات أو رموز.
cin >> للأرقام، وgetline للنصوص اللي فيها مسافات.
