index.html

style.css
1.box { 2 width: 200px; 3 height: 120px; 4 background-color: rgb(57,197,207); 5 /* أو hex: #39c5cf */ 6}

صور الخلفية

background-image و التكرار

لو الصورة صغيرة والمساحة كبيرة، هي بتتكرر (repeat) تلقائيًا عشان تملى المكان

style.css
1.box { 2 width: 240px; 3 height: 120px; 4 background-image: url("small.jpg"); 5 /* الصورة 24×24 بس المساحة أكبر → بتتكرر */ 6}
صورة صغيرة + مساحة كبيرة = تكرار 👇

مكان الصورة

background-position

بتحدد مكان الصورة جوه العنصر — بالبكسل أو بكلمات زي top/bottom/center

style.css
1.box { 2 border: 2px solid #30363d; 3 background-repeat: no-repeat; 4 background-position: 10px 20px; 5 /* أو: top right */ 6 /* أو: bottom center */ 7}
3 قيم مختلفة 👇

مقاس الصورة

background-size

cover بتمط الصورة تملى المكان (ممكن تقص جزء) — contain بتتأكد إن الصورة كلها ظاهرة

style.css
1background-size: 100%; 2background-size: 150px 150px; 3background-size: cover; /* stretch لتملى */ 4background-size: contain; /* الصورة كلها تبان */

نقطة البداية

background-origin

بتحدد الصورة بتبدأ منين بالنسبة للـ padding والـ border

padding-box
الافتراضي
content-box
border-box

بص لمكان الصورة في كل مربع بالنسبة للحد المنقّط (border) — دلوقتي الفرق واضح بين الثلاثة: border-box بتبدأ من أول الحد نفسه، padding-box بعد الحد، content-box بعد الحد والـ padding

الصيغة المختصرة background

بدل ما تكتب كل خاصية لوحدها، تقدر تكتبهم كلهم في سطر واحد

style.css
1div { 2 height: 150px; 3 width: 150px; 4 border: 6px dashed rgb(0,166,255); 5 padding: 8px; 6 /* الصيغة المختصرة: */ 7 background: 8 rgb(190,213,213) 9 url("small.jpg") 10 no-repeat center/50% 11 border-box; 12}

وقفة تدريب

تمرين على خصائص الخلفية 📝

اعمل div بمقاس 300×300، حط له border منقط وpadding
حط background-color و background-image مع بعض
جرب background-repeat: no-repeat و background-position: center
جرب background-size: 50% وقارنها بـ cover و contain
جرب background-origin: border-box بدل الافتراضي
بونص: اكتب كل ده في سطر واحد بالـ shorthand

circle vs ellipse
