viewport meta tag

من غيره، متصفح الموبايل بيحاول يعرض الصفحة كأنها على شاشة عريضة (زي 980px) وبعدين يزوّم أوت — يعني كل حاجة تبان صغيرة ومحتاجة zoom يدوي.

index.html
<head> <meta name="viewport" content="width=device-width, initial-scale=1.0"> </head>

الأداة الأساسية

@media query

بتطبّق قواعد CSS بس لما عرض الشاشة (أو خاصية تانية) يحقق شرط معين.

style.css
.banner { background: blue; } @media (max-width: 700px) { .banner { background: orange; } }
🔴 لايف — بيتغير مع عرض الشاشة الحقيقي
قلّل عرض نافذة المتصفح عشان تشوف التغيير 👇
💻 الشاشة واسعة — أزرق📱 الشاشة ضيقة — برتقالي

min-width ولا max-width؟

الفرق بين max-width و min-width

max-width: القاعدة تتطبق لما الشاشة أصغر من أو تساوي القيمة (مناسبة للموبايل). min-width: القاعدة تتطبق لما الشاشة أكبر من أو تساوي القيمة (مناسبة لسطح المكتب).

style.css
@media (max-width: 700px) { .box-a { background: red; } } @media (min-width: 701px) { .box-b { background: green; } }
🔴 لايف
box-a بتحمرّ على الضيق، box-b بتخضرّ على الواسع 👇

دي مش قواعد ثابتة — أرقام شائعة بس. الأهم إنك تكسر التصميم عند النقطة اللي محتواك فعلًا بيبوّظ فيها، مش عند رقم معين.

استراتيجية الكتابة

Mobile-first

تكتب الأساس (الافتراضي) للموبايل الأول، وبعدين تزوّد min-width media queries عشان تحسّن التصميم على الشاشات الأكبر.

style.css
.card { width: 100%; } /* أساس: موبايل */ @media (min-width: 700px) { .card { width: 48%; } /* تحسين: شاشة أكبر */ }
🔴 لايف
الكروت بتاخد العرض كله على الموبايل، ونص العرض على الشاشة الواسعة 👇

Navbar متجاوب

الناف بار بيبقى صف أفقي على الشاشة الواسعة، ويتحول لعمود (stacked) على الموبايل.

index.html
<nav class="nav"> <a>الرئيسية</a> <a>المنتجات</a> <a>تواصل معانا</a> </nav>
style.css
.nav { display: flex; flex-direction: row; gap: 12px; } @media (max-width: 700px) { .nav { flex-direction: column; } }
🔴 لايف
قلّل عرض النافذة تشوف الروابط بتترص عمودي 👇

Card Grid متجاوب

شبكة الكروت بتبدأ بعمود واحد على الموبايل، وبتزود عدد أعمدتها كل ما الشاشة تكبر.

style.css
.grid { display: grid; grid-template-columns: 1fr; gap: 10px; } @media (min-width: 700px) { .grid { grid-template-columns: repeat(2, 1fr); } } @media (min-width: 1000px) { .grid { grid-template-columns: repeat(4, 1fr); } }

مراجعة سريعة

viewport meta tag أول حاجة تحطها عشان الموبايل يعرض الصفحة بمقاسها الحقيقي
@media query بتطبّق CSS بس لما شرط عرض الشاشة يتحقق
max-width للشاشات الصغيرة، min-width للشاشات الكبيرة
الـ breakpoints (480 / 768 / 1024) أرقام شائعة بس، مش قواعد ثابتة
Mobile-first: ابدأ بتصميم الموبايل، وكبّر بـ min-width
أمثلة حقيقية: navbar بيستقيم عمودي، card grid بتزود أعمدتها، الصور max-width:100%، الخط بيكبر، والسايدبار بيختفي

جرّب دلوقتي تعمل صفحة صغيرة وتخليها Responsive بنفسك 💪
