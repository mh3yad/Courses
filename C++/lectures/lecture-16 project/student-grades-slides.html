الفكرة

عندنا فصل فيه كذا طالب، كل طالب ليه اسم ودرجات مواده — البرنامج يحسب المتوسط لكل واحد ويقولنا مين أعلى واحد

يعني زي ما المدرس يقف يجمع الدرجات بالآلة الحاسبة — بس إحنا نعملها بكود C++ مرة واحدة

📦

▼
🔁
function المتوسط
بتجمع الدرجات وتقسم على عدد المواد

👑
function أعلى طالب

1#include <iostream> 2#include <string> 3using namespace std; 4 5const int SUBJECTS = 3; // number of subjects 6const int STUDENTS = 4; // number of students 7 8struct Student { 9 string name; 10 int grades[SUBJECTS]; // 1D array 11}; 12 13double average(const Student &s) { 14 int sum = 0; 15 for (int i = 0; i < SUBJECTS; i++) 16 sum += s.grades[i]; 17 return (double)sum / SUBJECTS; 18}

الكود — الجزء التاني

دالة أعلى طالب و الـ main

grades.cpp — part 2
1int topStudent(Student arr[], int n) { 2 int top = 0; 3 for (int i = 1; i < n; i++) 4 if (average(arr[i]) > average(arr[top])) 5 top = i; 6 return top; 7} 8 9int main() { 10 Student cls[STUDENTS] = { 11 {"Ahmed", {80, 90, 85}}, 12 {"Sara", {95, 88, 92}}, 13 {"Omar", {70, 75, 68}}, 14 {"Laila", {60, 65, 72}} 15 }; 16 for (int i = 0; i < STUDENTS; i++) 17 cout << cls[i].name << " -> average = " 18 << average(cls[i]) << endl; 19 int t = topStudent(cls, STUDENTS); 20 cout << "\nTop student: " << cls[t].name 21 << " with average " << average(cls[t]) << endl; 22 return 0; 23}

خطوة بخطوة

البرنامج شغال إزاي؟

1. بنعرّف struct Student — الأستاذ: name + grades[]
2. average() بتلف على الدرجات بـ for loop وتجمعهم
3. topStudent() بتقارن المتوسطات وبتفتكر مكان الأعلى
4. main بتطبع تقرير كل الطلبة + اسم الأعلى
