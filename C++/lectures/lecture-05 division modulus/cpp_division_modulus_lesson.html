الجزء الأول

الـ Modulus ده إيه أصلاً؟ 🤔

الـ Modulus يعني الباقي — الرقم اللي بيفضل بعد ما تقسم

modulus.cpp
1#include <iostream> 2using namespace std; 3 4int main() { 5 cout << 17 % 5; // هيطبع 2 6 return 0; 7}

ليه 2؟ عشان 5 × 3 = 15 و اللي باقي من 17 هو 2 ✅

إزاي بيشتغل

الـ Modulus شغال زي الساعة 🕐

فكّر فيها كده: الساعة ماشية في دائرة — لما توصل 12 بترجع تبدأ من 1 تاني

clock.cpp
1cout << 14 % 12; // هيطبع 2 2cout << 25 % 12; // هيطبع 1

استخدام عملي

الرقم ده بيقبل القسمة على 5 ولا لأ؟

القاعدة ذهبية: لو الباقي صفر يبقى الرقم بيقبل القسمة

divide.cpp
1int n = 20; 2 3if (n % 5 == 0) { 4 cout << "yes, divisible"; // 20 % 5 = 0 ✅ 5} else { 6 cout << "no"; 7}

نفس الفكرة تشتغل مع أي رقم: n % 3 , n % 7 , n % 9 ... إلخ

تطبيق مشهور

الرقم Odd ولا Even؟

Even 🟢
لو n % 2 == 0
يبقى الرقم Even (زوجي)
+
Odd 🟣
لو n % 2 == 1
يبقى الرقم Odd (فردي)
odd_even.cpp
1int n = 7; 2 3if (n % 2 == 0) 4 cout << "Even"; // 7 % 2 = 1 → مش هنا 5else 6 cout << "Odd"; // ✅ هيتطبع Odd

1234 % 10

عايز تشيل آخر رقم؟ اقسم على 10

remove_last.cpp
1int n = 1234; 2 3n = n / 10; // 123 → اتشال الـ 4 4cout << n; // هيطبع 123
