THE IDEA

يعني إيه operator؟

هو symbol بيطلب من C++ تعمل operation على values أو variables.

=

assign value

>

compare values

&&

combine conditions

مثال: age > 18 بيسأل: هل age أكبر من 18؟

ASSIGNMENT

assignment operators

بيغيروا value جوه variable.

assignment.cpp
int score = 10;     // score is 10
score += 5;           // same as: score = score + 5 → 15
score *= 2;           // same as: score = score * 2 → 30

= set · += add then set · *= multiply then set

INCREMENT / DECREMENT

++ و --

++ increment

يزوّد variable واحد.

int apples = 4;
apples++; // 5

-- decrement

ينقص variable واحد.

int lives = 3;
lives--; // 2

مفيدين جدًا مع counters في loops.

COMPARISON

comparison operators

بتعمل check وبتطلع true أو false.

comparison.cpp
int age = 20;
cout << (age > 18);   // true
cout << (age < 18);   // false
cout << (age == 20);  // true
cout << (age != 20);  // false
cout << (age >= 20);  // true
cout << (age <= 18);  // false

== compare · = assign — دول مش نفس الحاجة. >= و <= يعني "أكبر من أو يساوي" و"أصغر من أو يساوي".

LOGICAL

logical operators

&& AND

الشرطين لازم يبقوا true.

int age = 20;
bool hasId = true;
age > 18 && hasId; // true
int mark = 75;
mark >= 50 && mark <= 100; // true (range check)

|| OR

يكفي شرط واحد يبقى true.

bool hasCard = false;
bool hasCash = true;
hasCard || hasCash; // true
int day = 6;
day == 6 || day == 7; // true (weekend)

REVISION

نراجع بسرعة

  1. = assign، و += / *= shortcuts للتعديل.
  2. ++ تزود واحد، و -- تنقص واحد.
  3. comparison operators (>, <, ==, !=, >=, <=) بترجع true أو false.
  4. && محتاجة الشرطين؛ || محتاجة شرط واحد.
  5. افتكر: = مش زي ==.
