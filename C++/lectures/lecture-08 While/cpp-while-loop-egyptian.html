REAL LIFE

يعني إيه loop؟

في real life: كل يوم تصحى، تعمل routine، وبعدين تكررها اليوم اللي بعده. التكرار بيقف لما condition تتغير.

🔁

alarm

تضغط snooze طول ما أنت لسه نايم.

🎮

game

تلعب level طول ما عندك lives.

🛒

shopping list

تشتري item طول ما الليستة فيها items.

WHY?

ليه نحتاج loop؟

01

تكرار أقل

بدل 100 سطر شبه بعض، نكتب block واحد.

02

data أكبر

نعدّ students أو نمر على numbers بسهولة.

03

code أذكى

الـ condition تخلي التكرار يشتغل وقت ما نحتاجه بس.

SYNTAX

while loop syntax

while.cpp
int count = 1;

while (count <= 3) {
  cout << count << " ";
  count++;
}
// output: 1 2 3

DANGER

infinite loop يعني إيه؟

لما condition تفضل true للأبد، program يفضل يكرر ومش يوصل للنهاية.

wrong.cpp
int count = 1;
while (count <= 3) {
  cout << count;
  // count never changes!
}
الحل:
اسأل نفسك: هل variable جوه condition بيتغير؟

count++; لازم تكون موجودة في مكان منطقي.

DEBUG

debug الـ while loop

2

راجع condition

هل المقارنة صح؟ < ولا <=؟

3

راجع update

هل count++ جوا loop وبتوصل لنقطة stop؟

EXAMPLE 01

sum من 1 لـ 5

sum-up.cpp
int sum = 0;
int number = 1;

while (number <= 5) {
  sum += number;
  number++;
}
cout << sum; // 15

الـ number بتبدأ 1 وبتزيد لحد ما تعدّي 5.

EXAMPLE 02

sum من 5 لـ 1

sum-down.cpp
int sum = 0;
int number = 5;

while (number >= 1) {
  sum += number;
  number--;
}
cout << sum; // 15

الناتج نفسُه، لكن direction مختلف: البداية 5 والـ update بقت number--.

CONTROL

break vs continue

break

يخرج من الـ loop فورًا. باقي iterations مش هتشتغل.

if (number == 3)
  break;
≠

continue

يتخطى iteration الحالي بس، وبعدها يكمل الـ loop عادي.

if (number == 3)
  continue;

نفس المثال: break يقف عند 3؛ continue يتخطى 3 ويكمل اللي بعده.

REVISION

نراجع بسرعة

  1. while بتكرر code طول ما condition true.
  2. كل loop محتاجة: condition + body + update.
  3. infinite loop بتحصل لما الـ condition مش بتوصل لـ false.
  4. break بتخرج؛ continue بتتخطى iteration.
  5. direction يغيّر البداية والـ condition والـ update.
