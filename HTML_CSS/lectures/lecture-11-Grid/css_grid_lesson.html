التحكم في Layout
بطريقة ثنائية الأبعاد مع CSS Grid

أعمدة وصفوف ومسافات ومحاذاة، ومناطق باسمها كمان — بالتفصيل مع أمثلة عملية 📐

خريطة الدرس

إيه اللي هنغطيه النهاردة؟

1 Grid ولا Flexbox، وإزاي نفعّله بـ display: grid
2 الأعمدة والصفوف: وحدات ثابتة، %، auto ووحدة fr
3 اختصارات: repeat()، minmax()، auto-fill
4 المسافات بـ gap والمحاذاة بـ justify/align-content
5 تحديد مكان العناصر بالخطوط، وتسمية المناطق بـ grid-template-areas

بُعد واحد ولا اتنين؟

Grid ولا Flexbox؟

الـ Flexbox بيرتب العناصر في اتجاه واحد بس — صف واحد أو عمود واحد. أما الـ Grid فبيرتب العناصر في اتجاهين في نفس الوقت — صفوف وأعمدة متقاطعة مع بعض.

النظامالبُعدمناسب لإيه
Flexboxبُعد واحدأشرطة تنقل، صف أو عمود واحد من العناصر
Gridبُعدينتصميم صفحة كاملة، شبكات كروت، لوحات تحكم

خصائص الـ Grid بتتقسم مجموعتين: خصائص على الـ parent (الحاوية)، وخصائص على الـ children (العناصر جواها).

تشغيل الشبكة

display: grid

لازم نفعّل الخاصية دي الأول. من غيرها، أي خاصية تانية بتاعة grid مش هتشتغل خالص.

index.html
<div class="container"> <div>1</div> <div>2</div> <div>3</div> </div>
style.css
.container { display: grid; }
النتيجة 👇 (من غير أعمدة محددة)
1
2
3

عرض الأعمدة

grid-template-columns

بالبكسل بنحدد عرض دقيق للعمود؛ والنسبة المئوية بتقسم عرض الحاوية بالتناسب.

index.html
<div class="container"> <div>1</div><div>2</div><div>3</div> </div>
style.css
.container { display: grid; grid-template-columns: 100px 200px 70px; }
النتيجة 👇
100px
200px
70px

أحجام مرنة

auto ووحدة fr

auto بيوزع العرض تلقائي. fr هي حصة من المساحة الفاضية — 1fr 1fr 1fr بتعمل أعمدة متساوية من غير أي حسبة يدوي.

index.html
<div class="container"> <div>2fr</div><div>1fr</div> </div>
style.css
.container { display: grid; grid-template-columns: 2fr 1fr; }
النتيجة 👇
2fr
1fr

auto ولا fr؟

مين بياخد المساحة؟

لما auto تتحط جنب 1fr، وحدة الـ fr بتاخد كل المساحة الفاضية الأول — و auto بتصغر لحجم محتواها بس (زي fit-content).

index.html
<div class="container"> <div>auto</div><div>1fr بتاخد الباقي</div> </div>
style.css
.container { display: grid; grid-template-columns: auto 1fr; }
النتيجة 👇 — auto بتصغر لحجم النص
auto
1fr بتاخد الباقي

أقل كتابة

repeat()

repeat(count, size) بتكرر نفس النمط من غير ما تكتبه يدوي كل مرة.

index.html
<div class="container"> <div>1</div><div>2</div><div>3</div> </div>
style.css
.container { display: grid; grid-template-columns: repeat(3, 1fr); } /* زي كده بالظبط: 1fr 1fr 1fr */
النتيجة 👇
1
2
3

الصفوف بالطول

grid-template-rows

بتحدد ارتفاع الصفوف بنفس طريقة الأعمدة. الوحدات النسبية زي fr أو auto محتاجة ارتفاع صريح للحاوية (height) عشان تحسب النسبة منه.

index.html
<div class="container"> <div>100px</div><div>50px</div><div>150px</div> </div>
style.css
.container { display: grid; height: 300px; grid-template-rows: 100px 50px 150px; }
النتيجة 👇 (حاوية بارتفاع 300px)
100px
50px
150px

مدى مرن

minmax()

بتحدد مدى بين حد أدنى وحد أقصى — مفيدة عشان تسيب العمود يكبر مع المحتوى من غير ما ينكمش تحت حد معين.

index.html
<div class="container"> <div>minmax(100,200)</div><div>1fr</div> </div>
style.css
.container { display: grid; grid-template-columns: minmax(100px, 200px) 1fr; }
النتيجة 👇
minmax(100,200)
1fr

أعمدة متجاوبة

auto-fill + minmax()

بيحسب عدد الأعمدة تلقائي حسب عرض الحاوية — من غير أي media queries. لما نضمه مع minmax()، الأعمدة بتتمدد تملى المساحة المتاحة كلها.

index.html
<div class="container"> <div>1</div><div>2</div><div>3</div><div>4</div><div>5</div> </div>
style.css
.container { display: grid; grid-template-columns: repeat(auto-fill, minmax(90px, 1fr)); gap: 8px; }
النتيجة 👇 — الأعمدة بتتمدد تملى العرض المتاح
1
2
3
4
5

لو الحاوية اتسعت وفيه مساحة لعمود سادس فاضي، auto-fill هينشئه فاضي بردو — لو عايز الأعمدة الموجودة بس تتمدد وتاخد كل المساحة، استخدم auto-fit بدل auto-fill.

توضيع الشبكة نفسها

justify-content و align-content

index.html
<div class="container"> <div>1</div><div>2</div><div>3</div> </div>
style.css
.container { display: grid; grid-template-columns: repeat(3, 70px); justify-content: center; }
النتيجة 👇 (justify-content: center)
1
2
3
justify-content (الاتجاه الأفقي): start, center, end, space-between, space-around, space-evenly — لازم يكون فيه مساحة فاضية زيادة، فمش هيكون ليها تأثير لو الأعمدة أصلًا بتاخد العرض كله بـ 1fr
align-content (الاتجاه الرأسي): بتحاذي مسارات الـ grid رأسيًا، ومحتاجة ارتفاع صريح للحاوية

تحديد أماكن العناصر

خطوط الشبكة والامتداد

المسارات بيحددها خطوط مرقّمة (1، 2، 3...)، وآخر خط بيتحدد بـ -1.

index.html
<div class="container"> <div class="wide">ممتد</div> <div>2</div><div>3</div><div>4</div> </div>
style.css
.container { display: grid; grid-template-columns: repeat(3, 1fr); } .wide { grid-column: 1 / -1; } /* عرض كامل */
النتيجة 👇 (grid-column: 1 / -1)
ممتد على الـ3 أعمدة

نجمّع كل حاجة

تصميم صفحة كاملة

Header و Nav و Main و Sidebar و Footer — مع مد الـ Header والـ Footer على العرض كله بـ grid-column: 1 / -1.

index.html
<div class="page"> <header>الهيدر</header> <nav>الناف</nav> <main>المحتوى</main> <aside>السايدبار</aside> <footer>الفوتر</footer> </div>
style.css
.page { display: grid; grid-template-columns: 1fr 3fr 1fr; grid-template-rows: auto 1fr auto; } header, footer { grid-column: 1 / -1; }
النتيجة 👇
الهيدر
الناف
المحتوى
السايدبار
الفوتر

طريقة أوضح للقراءة

grid-template-areas

الخطوة 1: سمّي كل عنصر بـ grid-area. الخطوة 2: ارسم شكل الصفحة كخريطة على الـ parent — والنقطة (.) بتسيب خانة فاضية.

index.html
<div class="page"> <div class="head">head</div> <div class="nav">nav</div> <div class="main">main</div> <div class="side">side</div> <div class="foot">foot</div> </div>
style.css
.page { display: grid; grid-template-columns: 1fr 3fr 1fr; grid-template-areas: "head head head" "nav main side" "foot foot foot"; } .head{grid-area:head;} .nav{grid-area:nav;} .main{grid-area:main;} .side{grid-area:side;} .foot{grid-area:foot;}
النتيجة 👇
head
nav
main
side
foot

آخر حاجة

مراجعة سريعة

display: grid بتفعّل الشبكة على الـ parent — من غيرها باقي الخصائص مش هتشتغل
grid-template-columns / rows بتحدد عدد وحجم الأعمدة والصفوف: px، %، auto، أو وحدة fr للمساحة الفاضية
repeat() بتختصر تكرار نفس النمط، وminmax() بتحدد مدى بين حد أدنى وأقصى
auto-fill / auto-fit مع minmax() بيعملوا أعمدة متجاوبة من غير media queries
gap بيحط مسافات بين المسارات، وjustify-content / align-content بيحاذوا الشبكة نفسها جوه الحاوية
grid-column / grid-row بيحددوا مكان العنصر بخطوط مرقّمة، وبيسمحوا بالامتداد (زي 1 / -1)
grid-template-areas بديل أوضح للقراءة — بترسم شكل الصفحة كخريطة أسماء

كده نكون غطينا الأساسيات كلها — جرّب دلوقتي تبني صفحة كاملة بـ Grid من غير ما ترجع للسلايدات 💪
