من تغيير ناعم بسيط لحد حركات كاملة بالـ keyframes — من غير JavaScript ✨

الفكرة

transition يعني إيه؟

الـ transition بتخلي قيمة الخاصية تتغيّر بالتدريج على مدة زمنية، مش مرة واحدة. عشان تعملها لازم تحدد حاجتين: الخاصية اللي عايز تحركها، والمدة. وهي في الحقيقة اختصار لـ 4 خصائص:

1 transition-property — إيه الخاصية اللي تتحرك
2 transition-duration — الحركة تاخد قد إيه
3 transition-timing-function — منحنى السرعة
4 transition-delay — نستنى قد إيه قبل ما تبدأ

أول مثال

مربع 100×100 بيكبر في ثانيتين

حددنا transition على الـ width لمدة 2s. لما العرض يتغيّر، المتصفح بيحرّكه بالتدريج.

style.css
div { width: 100px; height: 100px; background-color: red; transition: width 2s; }

إيه اللي بيشغّلها؟

الـ Trigger

الـ transition بتبدأ لما قيمة الخاصية تتغيّر. غالبًا ده بيحصل جوه :hover أو :active أو :focus أو :checked.

style.css
div:hover { width: 300px; }
🔴 لايف
حط الماوس فوق المربع الأحمر 👇
2s

أكتر من خاصية

نغيّر كذا حاجة مرة واحدة

افصل بين الخصائص بـ فاصلة (,) ولكل خاصية مدتها. هنا: width ثانيتين، height 4 ثواني، background-color 3 ثواني.

style.css
div { transition: width 2s, height 4s, background-color 3s; }
🔴 لايف
حط الماوس وراقب كل خاصية بتخلص إمتى 👇
hover

سرعة الحركة

timing-function

بتحدد منحنى السرعة: ease (الافتراضي: بطيء ← سريع ← بطيء)، linear (سرعة ثابتة)، ease-in (بداية بطيئة)، ease-out (نهاية بطيئة)، ease-in-out (بداية ونهاية بطيئة).

style.css
#div1 { transition-timing-function: linear; } #div2 { transition-timing-function: ease; } #div3 { transition-timing-function: ease-in; } #div4 { transition-timing-function: ease-out; } #div5 { transition-timing-function: ease-in-out; }
🔴 لايف
حط الماوس على كل شريط وقارن السرعة 👇
linear
ease
ease-in
ease-out
ease-in-out

التأخير

transition-delay

بتحدد نستنى قد إيه قبل ما الحركة تبدأ. القيمة بالثواني (s) أو الميلي ثانية (ms). هنا فيه ثانية تأخير قبل البداية.

style.css
div { transition-delay: 1s; }
🔴 لايف
حط الماوس وعُد: ثانية انتظار ثم الحركة 👇
1s

طريقتين للكتابة

واحدة واحدة ولا shorthand؟

الاتنين بيدّوا نفس النتيجة بالظبط. الـ shorthand بترتّب القيم: الخاصية ← المدة ← المنحنى ← التأخير.

طريقة 1: واحدة واحدة
div { transition-property: width; transition-duration: 2s; transition-timing-function: linear; transition-delay: 1s; }
طريقة 2: shorthand
div { transition: width 2s linear 1s; }
🔴 لايف
حط الماوس على المربع 👇
width 2s linear 1s

الجزء التاني

CSS Animation يعني إيه؟

الـ animation بتخلي العنصر يتغيّر تدريجيًا من ستايل لستايل تاني، من غير JavaScript. تقدر تغيّر أي عدد من الخصائص، وأي عدد من المرات. وعشان تشتغل لازم تحدد keyframes — وهي بتقول العنصر هيبقى شكله إيه في أوقات معينة.

🔴 لايف
🔔

الأساس

@keyframes + name + duration

الـ animation-name بتحدد اسم الحركة، والـ animation-duration بتحدد بتاخد قد إيه. لو ما كتبتش duration مفيش حركة خالص (القيمة الافتراضية 0s). هنا المربع بيتحول من أحمر لأصفر في 4 ثواني. from = 0% وto = 100%.

style.css
/* كود الحركة */ @keyframes myAnimation { from { background-color: red; } to { background-color: yellow; } } /* العنصر اللي هنطبق عليه */ div { width: 100px; height: 100px; background-color: red; animation-name: myAnimation; animation-duration: 4s; }
🔴 لايف
اضغط على المربع لإعادة التشغيل 👇

بالنسب المئوية

مراحل كتير بالـ %

بالنسب تقدر تضيف تغييرات قد ما تحب. هنا اللون بيتغيّر عند 25% و50% و100%.

style.css
@keyframes myAnimation { 0% { background-color: red; } 25% { background-color: yellow; } 50% { background-color: blue; } 100% { background-color: green; } }
🔴 لايف
اضغط على المربع لإعادة التشغيل 👇

لون + مكان

نغيّر اللون والمكان مع بعض

تقدر تحرّك العنصر (left و top) وتغيّر لونه في نفس الوقت. لازم العنصر يكون position: relative عشان left/top يشتغلوا.

style.css
@keyframes myAnimation { 0% { background-color:red; left:0px; top:0px; } 25% { background-color:yellow; left:200px; top:0px; } 50% { background-color:blue; left:200px; top:200px; } 75% { background-color:green; left:0px; top:200px; } 100% { background-color:red; left:0px; top:0px; } } div { position: relative; animation: myAnimation 4s; }
🔴 لايف
اضغط على المربع لإعادة التشغيل 👇

التأخير

animation-delay

بتأخر بداية الحركة. 2s يعني نستنى ثانيتين قبل ما تبدأ. وكمان بتقبل قيم سالبة: -2s يعني الحركة تبدأ كأنها شغالة من ثانيتين.

style.css
div { animation-name: myAnimation; animation-duration: 4s; animation-delay: 2s; /* أو -2s */ }
🔴 لايف
الأول: delay 2s — التاني: delay -2s (اضغط للإعادة) 👇
2s
-2s

عدد المرات

animation-iteration-count

بتحدد الحركة تتكرر كام مرة. رقم زي 3 يعني تتكرر 3 مرات وتقف، وinfinite يعني تفضل شغالة للأبد.

style.css
.a { animation-iteration-count: 3; } .b { animation-iteration-count: infinite; }
🔴 لايف
الأول 3 مرات، التاني infinite 👇
3

قبل وبعد الحركة

animation-fill-mode

الحركة مش بتأثر على العنصر قبل أول keyframe ولا بعد آخر واحدة. الـ fill-mode بتغيّر ده: none (افتراضي)، forwards (يفضل على آخر ستايل)، backwards (ياخد أول ستايل أثناء الـ delay)، both (الاتنين).

style.css
div { animation-name: myAnimation; animation-duration: 3s; animation-delay: 2s; animation-fill-mode: both; }
🔴 لايف
اضغط على المربع لإعادة التشغيل 👇 (الأصفر = أول keyframe، الأخضر = آخر keyframe)
none
forwards
backwards
both

اختصار

الـ animation shorthand

بدل 6 خصائص، اكتبهم في سطر واحد بالترتيب: name ← duration ← timing-function ← delay ← iteration-count ← direction.

الطريقة الطويلة
div { animation-name: myAnimation; animation-duration: 5s; animation-timing-function: linear; animation-delay: 2s; animation-iteration-count: infinite; animation-direction: alternate; }
الـ shorthand
div { animation: myAnimation 5s linear 2s infinite alternate; }
🔴 لايف
نفس النتيجة بالظبط 👇

آخر حاجة

مراجعة سريعة

transition بتحتاج trigger (hover/focus...)، وanimation بتشتغل لوحدها بالـ @keyframes
transition: الخاصية ← المدة ← المنحنى ← التأخير
animation محتاجة name و duration، ولو duration مش موجودة مفيش حركة
from/to = 0%/100%، وبالنسب تعمل مراحل قد ما تحب
delay (ممكن سالب)، iteration-count (رقم أو infinite)، direction (normal/reverse/alternate)
fill-mode: none / forwards / backwards / both
الـ shorthand: name ← duration ← timing ← delay ← count ← direction
