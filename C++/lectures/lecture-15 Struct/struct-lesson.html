ليه محتاجين struct

لما البيانات تتبعتر

تخيل بتشتغل على بيانات كتاب: العنوان، المؤلف، السعر، عدد الصفحات. لو عملت لكل حاجة variable لوحدها، مفيش حاجة في الكود بتقولك إن كل الـ variables دي بتوصف نفس الكتاب. ولو عندك أكتر من كتاب، الدنيا هتتلخبط أكتر.

without_struct.cpp
✕ متبعتر
string title1 = "Clean Code";
string author1 = "Robert Martin";
double price1 = 250.0;
int pages1 = 320;
// دول كل واحد فيهم منفصل عن التاني، مفيش رابط بينهم

مثال من الواقع

فكّر في بطاقة الكتاب

في مكتبة حقيقية، كل كتاب ليه بطاقة واحدة مكتوب فيها كل معلوماته مع بعض — مش ورقة لوحدها لكل معلومة. الـ struct في ++C بيعمل بالظبط كده: بيجمعلك البيانات المرتبطة في نوع واحد جديد اسمه Book.

Basic Syntax

إزاي بنكتب الـ struct

بنبدأ بكلمة struct وبعدها اسم الـ type الجديد (هنا Book)، وجوه الأقواس بنكتب الـ members بتاعته بنفس شكل تعريف الـ variables العادي. ومتنساش ; بعد الـ }.

book.cpp
✓ Struct
struct Book {
    string title;
    string author;
    double price;
    int pages;
};
05 / 11
Create

بتعمل object إزاي

بتعمل variable من نوع Book زي أي data type تاني، وتملى الـ members بالـ dot operator. أو تديله كل القيم مرة واحدة بالترتيب.

main.cpp
Book b1;
b1.title  = "Clean Code";
b1.author = "Robert Martin";
b1.price  = 250.0;
b1.pages  = 320;

// أو أسرع من كده
Book b2 = {"The Hobbit", "Tolkien", 180.5, 310};
06 / 11
Read

بتقرا البيانات إزاي

عشان تقرا أي member جوه الـ struct، بتحط . بعد اسم الـ variable وبعدها اسم الـ member. زي ما بتوصل لصفحة في الكتاب.

main.cpp
cout << b1.title << endl;
cout << b1.price << endl;
// هيطبع: Clean Code  ثم  250
07 / 11
Write

بتغيّر البيانات إزاي

بنفس طريقة القراءة، تقدر تغيّر قيمة أي member وقتما تحب باستخدام نفس الـ dot operator.

main.cpp
b1.price = 199.99;
b1.pages = b1.pages + 10;
// السعر اتغير، وعدد الصفحات زاد 10
08 / 11
Function جوه الـ struct

مش بس بيانات، فيه functions كمان

تقدر تحط function جوه الـ struct نفسه. الـ function دي بتوصل لكل الـ members مباشرة من غير ما تكتب اسم الـ object قبلها.

book.cpp
struct Book {
    string title;
    string author;
    double price;
    int pages;

    void printInfo() {
        cout << title << " - " << author << endl;
        cout << "Price: " << price << endl;
    }
};
09 / 11
مثال شامل

كل حاجة مع بعض

دلوقتي خلينا نجمع كل اللي اتعلمناه في برنامج واحد كامل.

full_example.cpp
#include <iostream>
using namespace std;

struct Book {
    string title;
    string author;
    double price;
    int pages;

    void printInfo() {
        cout << title << " by " << author << endl;
        cout << "Price: " << price << " | Pages: " << pages << endl;
    }
};

int main() {
    Book b1 = {"Clean Code", "Robert Martin", 250.0, 320};
    b1.price = 199.99;
    b1.printInfo();
    return 0;
}

Revision

اللي لازم يفضل في دماغك

struct بيخليك تجمع بيانات مختلفة النوع في حتة واحدة.
بتعمل object منه زي أي data type عادي.
بتوصل للـ members بالـ dot operator ( . )
تقدر تقرا وتكتب فيهم زي أي variable عادي.
تقدر تحط function جواه تشتغل على نفس بيانات الـ object.
الـ struct بيخلي الكود منظم وأقرب لطريقة تفكيرك في المشكلة.
